# dictionary/

本目录是项目的**本地官方译名证据入口**。

公开仓库不会附带 Skyrim、DLC 或 Creation Club 的官方英中 XML。使用者应自行提供其合法取得或导出的 xTranslator 英中 XML 文件。

## 目录语义

- 工具递归读取 `dictionary/**/*.xml`。
- 不要求固定文件名、固定数量、固定 DLC 白名单或固定子目录。
- 放进这个目录的每个 XML 都会被视为“官方证据来源”，因此不要混入社区汉化、MOD 词典或个人术语表。
- 官方词典提供译名与用法证据，不是无条件字符串替换表。

`GLOBAL.md` 是从本地官方语料归纳出的共享世界观与语用背景；`GLOSSARY.md` 记录本项目跨 MOD 的翻译裁决。两者不能代替原始官方词典查询。
