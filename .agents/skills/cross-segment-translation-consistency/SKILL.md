# 跨片翻译一致性保障流程

当需要将大批量文本拆分为多个片段（通常 ≥3 片）进行并行翻译时，必须先完成跨片专名统一和长篇事实核对这两道前置工序，否则各片各自定形必然产生同源分裂，且长篇文本容易出现事实漂移。

## 一、跨片专名统一（派单前必做）

### 根因
各片在翻译时如果没有共用底料，会各自按音感或记忆为同一专名选定中文形式，导致同一专名在同一份译文里出现三到四种不同写法。这是系统性的，不是偶发错误，只要底料不全就会复现。

### 操作步骤
1. **全量枚举专名**：从原文中提取所有疑似专有名词（角色名、地点名、组织名、物品/魔法术语等），形成候选清单。
2. **查询官方分布**：对每个候选专名，用确定性方式（字符串匹配、官方译名表查询、已校对段落检索）查它在全部已有官方语料中的标准中文写法。
3. **写入共用底料**：将查询结果整理为一份"译名对照表"，一次性下发给所有翻译 agent，作为不可绕过的约束源。
4. **制定规则**：明确两条强制规则：
   - 「表中已有专名必须照表落形，禁止另定。」
   - 「表中未收录的表外专名，先查官方分布再定形，不得凭直觉首定即终定。」
5. **验证覆盖度**：统计候选专名中被查到的比例，确保底料覆盖率接近 100%；若有大量漏网专名，说明原文中出现了尚未被官方定型的新造词，需要单独处理并补录。

### 常见陷阱
- 底料只收了各片当前可见范围内的名字，遗漏了出现在其他片的同一名词 → 分裂不可避免。
- 依赖 agent 自行检索：agent 之间无法互相发现对方已确定的写法，必须在统一下发之前完成全量查询。
- 把"分片后的局部结果合并后再去重"当作解决方案：此时分裂已经发生，再去统一属于事后修补而非事前预防，代价更高且可能破坏已有的翻译质量。

## 二、长篇文本事实漂移核对（边翻边核）

### 核对项（逐段检查）
以下四类内容最容易发生漂移，每段译文完成后必须逐项确认：

1. **逻辑连接词**：因果、转折、让步关系是否与原文完全对应。误译或漏译会导致剧情线扭曲。
2. **情态强度**：必须 / 应该 / 可以 / 或许这类词的语气层级，在系列文本中尤其容易渐变走偏。
3. **代词指代**：他 / 她 / 它 / 他们对应的原文对象，长段落后更容易串位。
4. **数字**：数值、数量、顺序号，这类可计算事实绝不能靠语义近似处理。

### 系列文本额外要求
若翻译的是同一作者的多部作品或同一个世界观下的不同章节：
- 检查**语域一致性**：同一个作者在不同章节使用的词汇风格应当稳定，除非原文本身发生了故意的语气变化。
- 让**叙述语气随原文处境变化**：不同场景（战斗、日常、内心独白）的措辞应有区分，但区分依据必须是原文的结构信号，而不是译者自行发明。

### 分工原则
- 凡是可以写成 `==`、正则匹配、集合查找、计数的校验任务，交给确定性脚本，不要委托给语言模型自行判断。
- LLM 负责语义层面的核验（译名是否合适、上下文是否通顺、语气是否符合处境），程序负责字符级精确比对。两者不可颠倒顺序。

## 三、流程总览

```
拆片前
  ↓
① 全量枚举 + 官方查询 → 译名对照表
  ↓
② 写入共用底料 + 制定「表内照落、表外先查」规则
  ↓
并行翻译（各片持有底料，互不干扰）
  ↓
边翻边核：连接词、情态、代词、数字
  ↓
成稿后跨片审校：用全书术语索引检测残留不一致
```
